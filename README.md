# Starbucks – Three-Statement Model & DCF Valuation

A linked three-statement financial model and DCF valuation of **Starbucks (SBUX)**: FY2024–FY2026 actuals, FY2027–FY2031 forecast, $ millions.

## Build
- **Assumptions** sheet drives every forecast – change one blue cell and all statements and the DCF update
- **Income statement, balance sheet and cash flow** linked together; balance check row reads 0
- **Analysis** of growth, margin, liquidity, leverage and cash-flow ratios
- **DCF**: unlevered free cash flow, WACC via CAPM, Gordon-growth terminal value
- **Sensitivity** of value per share across WACC and terminal growth rates

## Key outputs
- WACC **8.5%**, terminal growth **2.5%**
- Enterprise value **$80.4 billion**; equity value per share **$62.12** vs a share price of $93.58 (Oct 2026), about **34% downside**
- Terminal value is 78% of enterprise value
